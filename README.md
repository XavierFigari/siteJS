# siteJS

Le but de ce site est de développer en mode agile des fonctionnalités dynamiques “classiques” trouvées aujourd'hui sur un site web.

Le langage utilisé est le JavaScript, le HTML et le CSS.

## Fonctionnalités
- Page d’accueil : Affiche un feed dynamique.
- Page Gallery : Présente une galerie d'images.
- Carrousel : Un carrousel d'images interactif.
- Formulaires : Différents formulaires pour l'interaction utilisateur.
Page Jeux : Une page dédiée aux jeux.
